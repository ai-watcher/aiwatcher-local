Status Standard

Done

Implemented and locally validated

Done means the code path exists and has automated or local validation. It does not automatically mean every host surface has been verified live.

Live claim gate

Platform claims require proof

Cross-platform interception must be proven with hook-status, observed host UI behavior, or extension telemetry. Session logs alone are not proof that a hook fired.

Partial

Useful but incomplete

Partial means a user can get value today, but the missing pieces are listed explicitly so the suite does not overclaim.

Not built

No moat credit yet

Not built items should not appear in marketing claims. They stay here until they are implemented and validated against the relevant workflow.

Acceptance Rules

Privacy

Local-first evidence

Prompt text and source code stay local by default. Hashes, decisions, aggregate usage, and local evidence can be recorded. Content collection must be explicit.

Honesty

Measured beats speculative

Before enough history exists, savings must be labeled estimated or API-equivalent. Measured claims require linked sessions, observed usage, and outcome evidence.

UX

Minimum touchpoints

Low-risk work should pass silently. High-risk work should require a clear decision. Unsupported surfaces should offer Prompt Companion or MCP without pretending true interception exists.

Friction

Infer first, ask only to confirm

Handoff and outcome tracking should not feel like developer paperwork. AIWatcher should infer likely outcomes from local evidence, suggest a handoff when useful, and ask for one-click confirmation only when confidence is low.

Control

Mid-session protection is launch-critical

Preflight alone is not enough. Loop stopping, runaway velocity alerts, and dangerous command gates are the biggest remaining difference between a dashboard and a control loop.

Coverage Guidance

Do not claim universal interception. Hooks work only where the host tool invokes prompt lifecycle hooks. Claude Desktop general chat and some desktop surfaces may write logs but not execute hooks. For those, AIWatcher must use Prompt Companion, MCP, browser extension, or editor extension patterns.

What Is Missing

P1 · moat first

Turn evidence into durable linkage

Outcome evidence exists, but the moat needs passive snapshot capture from daily scans, durable session-to-commit records, branch context, test transitions, revert/churn detection, and same-file re-prompt signals. Finish this first because every linked session strengthens the intervention graph.

P1 · control loop

Build live control

Loop detection, runaway token velocity, and dangerous command gates are still not built. This is the biggest gap against the control-loop thesis after durable linkage.

Launch gate

Verify cross-platform claims

Run S-03, S-08, S-09, S-10, S-11, and S-15 on real devices. If a surface does not invoke hooks, document the fallback path. Treat this as a continuous release bar, not a separate product pillar.

P2 · habit

Polish weekly digest

Report and journal exist. Package them into a weekly ritual that shows spend by tool, gates fired, commands blocked, outcomes confirmed, and open follow-ups.

P2 · workflow

Finish handoff into daily work

PR #11 completes explicit session-review handoff: visible dashboard CTA, target-specific capsule, copyable brief, commit/file pointers, and privacy opt-in prompt excerpt. Still needed: CRITICAL auto-trigger, one-click host launch where APIs permit it, session close marker, UI search by outcome/topic, and quota-aware lane switch.

P2 · prevention

Broad work breadth heuristic

Broad UI/product requests without security words still pass too quietly. Add file-scope and task-shape signals so AIWatcher catches expensive multi-file work.

P3

Cost per surviving change

This needs enough durable linkage history before claims are credible. Keep it behind the evidence flywheel instead of forcing a premature metric.

P3

Non-code outcome proxies

Brainstorming, writing, and analysis sessions need weaker confidence signals such as copy, revisit, abandonment, and same-topic re-prompting.
